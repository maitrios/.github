# maitri

**maitri** (*MY-tree*) is a beautiful, opinionated Linux desktop made by [Kindness](https://kindness.ai).
It turns a fresh Arch Linux install into a fully configured Hyprland desktop with sane defaults and a
curated set of apps.

*Maitrī* is Sanskrit for loving-kindness. That's the feeling we're after: a calmer, kinder computer.

maitri is a friendly fork of [Omarchy](https://omarchy.org) and tracks its releases. Huge thanks to that
project for the foundation.

## Repos

- [maitri](https://github.com/maitrios/maitri): the desktop itself (commands, defaults, the Quickshell shell, themes, migrations, the ISO)
- [maitri-pkgs](https://github.com/maitrios/maitri-pkgs): PKGBUILDs and CI for the signed `[maitri]` package repo
- [maitri-vicinae](https://github.com/maitrios/maitri-vicinae): the Vicinae extension behind the launcher, menu and pickers
- [maitri-fish](https://github.com/maitrios/maitri-fish): the fish config behind the login shell
- [maitri-trackpoint](https://github.com/maitrios/maitri-trackpoint): an optional ThinkPad TrackPoint bar widget

## Get it

Grab the latest ISO from [maitri releases](https://github.com/maitrios/maitri/releases), write it to a
USB stick and boot. Found a bug? [Open an issue](https://github.com/maitrios/maitri/issues).
